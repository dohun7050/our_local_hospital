# 우리지역병원

React와 Vite 화면, Node.js 서버로 구성합니다. AI SPACE에서는 Node.js 20, 포트 3000을 사용합니다.

## 실행

Node.js 20.19 이상 설치 후 이 폴더에서 실행합니다.

```powershell
Copy-Item .env.example .env
npm install
npm run build
npm start
```

브라우저에서 http://localhost:3000 을 엽니다. `.env`의 빈 값을 채운 뒤 서버를 재시작합니다. `npm run dev`는 화면 개발 전용입니다. 전체 기능 확인에는 위 build/start 순서를 사용합니다.

## 키 설정

- GEMINI_API_KEY: 새로 발급한 비밀 키. 비워두었습니다.
- GEMINI_MODEL: 기본 gemini-2.5-flash. 계정에서 이용 가능한 모델로 변경할 수 있습니다.
- KAKAO_REST_API_KEY: 카카오 로컬 병원 검색용 비밀 키.
- KAKAO_JAVASCRIPT_KEY: 지도 표시용 공개 키. 카카오 개발자 콘솔에서 로컬 주소와 실제 배포 도메인을 허용하고 지도 서비스 사용 설정을 확인하세요.

AI SPACE에서는 웹 콘솔의 서버 환경변수에 설정합니다. Gemini/REST 키는 브라우저로 전달하지 않습니다. 기존 채팅의 Gemini 키는 사용하지 않았습니다. `.env`는 업로드하지 않습니다.

## 동작

검색 / 병원결과 / 네이버지도 / 앱 정보 4개 탭. 대구 중구·동구·북구·수성구 선택 또는 위치 동의 후 반경 10km 검색. Gemini가 최대 3개의 진료과 후보를 반환하면 카카오 검색을 병렬 수행합니다. 공공 최대 2개, 민간 최대 3개, 미확인 최대 3개를 진료과별 표시합니다. 같은 병원은 진료과가 다르면 다시 나올 수 있습니다. 네이버지도는 병원명과 주소 검색을 새 창으로 열며 네이버지도 내에서 길찾기를 선택합니다.

기획서의 가상 병원 8개는 앱 정보의 시연 화면에서만 사용합니다. 실제 결과에 섞지 않습니다. 로그인, 예약, 진단, 가격 추정은 제공하지 않습니다.

## 공공 민간 분류의 제한

카카오 응답에는 설립 주체가 없습니다. 명칭, 규모, 비영리 여부만으로 분류하지 않습니다. ownership.json의 검증된 카카오 장소 ID와 운영주체·출처가 있을 때만 분류합니다. 현재 목록은 비어 있으므로 실검색 병원은 미확인으로 표시됩니다. 공공 1~2개와 민간 0~3개 표시를 실제로 보장하려면 확인 자료를 등록해야 합니다. 검색 범위에 병원이 없으면 가짜 병원을 채우지 않습니다.

등록 형식 (실제 확인한 값으로만 작성):

```json
[{"kakaoId":"실제 장소 ID","type":"public","operator":"확인한 설립 운영기관","source":"https://공식확인출처"}]
```

private는 개인·의료법인·학교법인 등 민간 주체이며 공공기관 설립 병원은 public입니다. 국립대학병원을 민간 학교법인과 혼동하지 않아야 합니다.

## 검증 범위

`npm test`로 분류·개수 상한·좌표 검증을 확인합니다. 실제 API 통합과 20~30초 응답 목표는 모든 키 설정 후 실측해야 합니다. 서버 전체 요청 제한 25초, 화면 대기 제한 29초를 둡니다. 진료과 검색 결과는 실제 해당 진료를 현재 제공한다는 확약이 아닙니다. 전화로 확인해야 합니다.
